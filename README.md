A multilingual full-stack platform for a beauty salon, built with TanStack Start, React, TypeScript, PostgreSQL, Prisma, and Clerk.

- Localized customer experience in English, German, and Russian

- Secure authentication and role-protected administration
- Product, service, inventory, and preorder management
- Responsive UI with light and dark themes
